
## 📝 注意事项

1. **保持一致性**：所有新增页面应遵循交易风格配色
2. **使用变量**：优先使用 `variables.scss` 中定义的颜色变量
3. **测试对比度**：确保文字与背景的对比度符合可访问性标准
4. **绿涨红跌**：股票相关数据使用绿色（上涨）和红色（下跌）
