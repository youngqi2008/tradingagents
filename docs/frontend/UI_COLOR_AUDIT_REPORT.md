### ⚠️ 需要注意的地方

#### 1. **内联样式中的硬编码颜色**
部分组件使用了内联样式，包含硬编码的颜色值：

**位置**：
- `Analysis/SingleAnalysis.vue`: 多处内联样式使用 `#909399`, `#409EFF` 等
- `Analysis/BatchAnalysis.vue`: 内联样式中的颜色值
- `Stocks/Detail.vue`: 内联样式

**建议**：
- 优先使用 CSS 类而不是内联样式
- 如需使用内联样式，使用 CSS 变量或 SCSS 变量

#### 2. **Element Plus 组件默认样式**
部分 Element Plus 组件可能仍使用默认的浅色样式：

**可能受影响的组件**：
- 下拉菜单 (el-select-dropdown)
- 弹出层 (el-popover)
- 工具提示 (el-tooltip)
- 日期选择器 (el-date-picker)

**解决方案**：
已在 `trading-theme-fixes.scss` 中添加全局覆盖

#### 3. **动态生成的内容**
部分通过 JavaScript 动态生成的内容可能包含硬编码颜色：

**位置**：
- `Analysis/SingleAnalysis.vue`: h() 函数中硬编码的颜色
- 报告渲染：Markdown 渲染后的样式

**建议**：
- 使用 CSS 类而不是内联样式
- 通过 CSS 变量控制颜色

## 🎨 统一配色规范

### 背景色层级
```scss
Level 1 (主背景): #000000  // 纯黑
Level 2 (次要背景): #1a1a1a  // 深灰
Level 3 (第三级): #2a2a2a  // 中灰
Level 4 (卡片): #1e1e1e  // 卡片灰
```

### 文字颜色层级
```scss
Primary (主文字): #ffffff  // 白色
Secondary (次要): #b0b0b0  // 浅灰
Tertiary (第三级): #808080  // 中灰
```

### 功能色
```scss
Primary (主色): #1E88E5  // 深蓝色
Success (上涨): #00C853  // 绿色
Danger (下跌): #F44336  // 红色
Warning (警告): #FFA726  // 橙色
Info (信息): #78909C  // 灰蓝色
```

### 边框色
```scss
Default: #333333  // 深灰
Light: #404040  // 中灰
```

## 📝 美化建议

### 1. **渐变使用规范**
- ✅ **推荐**：深色渐变 (`#1a1a1a` → `#2a2a2a`)
- ❌ **避免**：浅色渐变、彩色渐变（除非特殊用途）

### 2. **卡片样式规范**
- 背景：`#1e1e1e`
- 边框：`1px solid #333333`
- 圆角：`8px`（统一）
- 阴影：`0 4px 12px rgba(0, 0, 0, 0.5)`

### 3. **按钮样式规范**
- 主要按钮：深蓝色背景 (#1E88E5)
- 成功按钮：绿色背景 (#00C853)
- 危险按钮：红色背景 (#F44336)
- 默认按钮：深灰色背景 (#2a2a2a)

### 4. **输入框样式规范**
- 背景：`#2a2a2a`
- 边框：`1px solid #333333`
- 文字：`#ffffff`
- 占位符：`#808080`

### 5. **表格样式规范**
- 表头背景：`#1a1a1a`
- 表格背景：`#1e1e1e`
- 行悬停：`#2a2a2a`
- 边框：`#333333`
